# 🛒 CodeAlpha E-Commerce Store

A modern full-stack E-Commerce web application built as part of the CodeAlpha Full Stack Development Internship.

---

## 🚀 Features

✅ User Registration & Login  
✅ JWT Authentication  
✅ Product Listing  
✅ Dynamic Product Fetching  
✅ Shopping Cart  
✅ Add/Remove Cart Items  
✅ Order Placement  
✅ MongoDB Database Integration  
✅ Responsive Modern UI  
✅ REST API Backend  

---

### Frontend

- JavaScript

### Backend

- Express.js

- JWT (JSON Web Token)

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Vishwanath810/CodeAlpha_EcommerceStore.git
```

### 2️⃣ Navigate Into Project

```bash
cd CodeAlpha_EcommerceStore
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Create .env File

```env
MONGO_URI=YOUR_MONGODB_CONNECTION_STRING
PORT=5000
```

### 5️⃣ Start Backend Server

```bash
npm run dev
```

### 6️⃣ Run Frontend

Open:
```bash
frontend/index.html
```

using Live Server.
